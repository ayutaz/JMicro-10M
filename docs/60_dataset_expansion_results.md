# 短い物語教材60M→200M・同量追加1Bの比較結果

2026-10-05 JST。[計画58](58_dataset_expansion_proposal.md)の段階1〜3を実施した。**常識の選択問題は改善したが、生成の一貫性・停止は改善せず、新200M条件は不採用**。元final10BのWeb UIへ復帰し、今回の範囲で停止する。Base/Chat品質目標は未達。

## データ量と学習量

一般Web trainは既存12,225,819,077 tokensのまま再処理していない。増やしたのは短い物語の準備量で、旧59,963,449 tokensを保持し、新しい公開日本語訳TinyStories140,036,743 tokensを追加、計**200,000,192 tokens / 1,161,923全文 / 822,869,721 UTF-8 bytes**となった。

新規499,066全文は`shibatch/TinyStories-JA` revision`155b4e5842076c90e07a4934d5b68410fe21f65f`の公式train4ファイルから取得。公開LFS SHA256を確認し、公式validation/testを取得・使用していない。翻訳元family hashによる1%除外とローカル完全一致61,995件の除外を実施。途中を切ってEOSを付けず、32–512 body tokens等の全文選別を用いた。40全文の個別診断では弱例18を開示し、全件品質の保証とはしていない。合成教科書はmetadataの確認だけで本文は学習していない。取得・変換・保存等の準備実経過145.021秒、上限1800秒以内。[実行詳細59](59_dataset_expansion_execution.md)と保存ready/source/receiptを参照。

## 残った課題と増量の解釈

各カテゴリ8生成の記述的集計では、数量の関連性2点は両条件0/8。一個食べた後のりんごを二個と答えず菓子の話へ移るなど、入力の数量を保持できない。新条件の日常一貫性は0/8、局所文脈一貫性も0/8。窓から雨が吹き込む場面で再度窓を開ける、甘味を食べない姉に菓子を選ぶ、母が母自身へ答えるなどの失敗を個別に保存した。一方、友人が駅に到着する、誕生日に花を贈るなど保持できる例もあり、全生成が失敗するわけではない。カテゴリは追加の採用gateではない。

**量だけを変えた実験ではない**。新sourceは合成された日本語訳の物語であり、poolの平均body長88.462→170.129、EOS/1000tokens11.054→5.810。実短文EOS教師も旧2,210,250→新1,161,577（約52.55%）となった。長さ・EOS密度の±5%不一致を学習前に開示して凍結済み。少ない終端教師がEOS減少に関係した可能性はあるが、sourceの意味品質と長さの変更から分離できず、原因の確定にはならない。

旧文章の反復利用を減らす増量は達成したが、新pool全体が元モデルに未見の独立200Mだとは保証しない。主Webとの独立全corpus重複・評価混入監査は未完了。したがって、この結果は「データを増やしても精度が上がらない」「学習が飽和した」「10Mの容量限界に達した」という結論を支持しない。今回の拡張条件では常識に改善があり、目標とする生成・停止の改善は得られなかった、という範囲の結果である。

## 採否・確認・停止

原品質gateの一貫性+8/80、対応区間下限>0、EOS非悪化は不合格。反復非悪化・raw失敗0・BPB相対+1%以内・内容的完結は合格。実用gateの一貫性27/80、適切完結27/80、EOS37/80は未達（反復18/80以下は合格）。保存Web対照との各原条件は通るが、全一次条件は満たさない。**新条件は不採用、事前分岐に従い条件付き全文89,416 / 生成400 / 長文評価は起動していない**。基準を緩めて結果を採用しない。

関連CPU5tests、実CUDA全state連続/再開25checks、一次v2の35evidencechecksが成功。凍結v1 reviewerにあったLR照合の1更新ずれは別v2で修正し、実schedulerの使用LR/保存後LRの2testsが成功。学習コード・config・schedule・採用条件を変更せず、v2と凍結v1のhashを保存した。最終要求別20checksも成功し、実process終了、元UIの実processとHTTP応答、report/judgment/hashを実確認した。

終端checkpointと全metrics/source/raw/annotationsはLinux `reports/phase6/dataset-expansion-1b-20261005/`へ保持する。旧final SHA`fd10dc1b358327bdbd8d3d58118c2cb096fc53d02b036f070e453911edf2b82a`、新final SHA`7932c04d905c0903eee338f08da2b3c44f5bde8fffc8dae237381de1f15c9391`。Windowsへresult/review/annotations/categories/judgment/completionを保存し、データ本体・checkpointはGitに含めない。

科学PID239609は終了。元final10B UIの実PID359102 / boot`53f39671-20b4-4bd5-9b9c-cd6b1e4d1bfe` / start_ticks7216365、ready2026-10-05T08:29:21.306388Z。HTTP `/api/model`は親SHA`410f975d848938627aafb4fa1d5483bf45fadbb7f9c05ed7d1c8f9d45c368290` / training_tokens10,000,007,168 / busy=false。今回の候補へUIを差し替えていない。

次回の提案は、さらに無条件に量を増やす前に、条件保持と指示対象の失敗を教材側で診断し、source品質・長さ・EOS密度をそろえた小さいtrain-only教材を同量予算で比較すること。これは提案で、新しい教材・GPU jobは開始していない。今回の段階1〜3はreport/local commit・元UI復帰で停止し、20B/50B/Chat/protected test/push/publicationには進まない。
