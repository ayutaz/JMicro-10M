## 原因について分かったことと、まだ分からないこと

先行した[800応答・640候補尤度の診断159](159_chat_recovery_diagnosis_results.md)では、正しい著作Assistant履歴でも二属性回答は両モデル0/80で、長い履歴の単属性も弱かった。通常文のBaseにも計算と訂正の失敗が残った。samplingの全3seedも明確な改善を示さなかった。自分の誤答への固着、SFTの教師内容、Baseの意味能力のいずれか一つだけを唯一の原因にはできない。

今回C1の変形TRAIN32件の本文mean NLLは0.001981まで下がったが、新DEV80の本文は2.054054で、C0の2.022204より悪かった。従来形の補助TRAIN32も0.002801→0.231961へ悪化した。少数TRAINに適合しても未知入力と既存形への転用を保証しない。これだけで統計的な過学習の唯一原因や全TRAINの暗記を証明したとも言わない。

現在の著作教師は主として一つの値を短く返す課題で、二つの最新値を組み合わせて答える教師の不足が次の未回答仮説になる。正答が32token以内に収まる評価でも失敗するので、上限を増やすだけでの解決は示されていない。入力配置を変えたこの一条件の失敗を、全ての多様化手法や10Mモデルの不可能の証明にはしない。

参考Akebonoも、固定revisionで実際に同じ既知20問を試した比較では内容5/20だった。[実比較152](152_answer_learning_diagnosis_results.md)。モデル固有の語彙・会話形式・学習履歴が異なり、公開例の印象やパラメータ数だけでは差の原因を確定できない。
