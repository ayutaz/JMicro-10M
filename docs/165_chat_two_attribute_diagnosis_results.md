# 二つの情報を答える学習と転用の診断結果

2026-10-18。**教材64問は全て学習でき、同じ質問形式なら未学習の値も30/32問で答えられた。一方、質問形式を変えた二項目回答は0/16問で、一般会話にも退行があった。今回の候補は採用しない。** [実行条件164](164_chat_two_attribute_diagnosis_execution.md)に沿った5工程と、全1,973応答の確認を完了した。

## 小集合では学べたが質問形式への転用が弱い

元Baseからfresh Adamで483更新、250,003 Assistant教師を学習した。同じ10M、seed42、LR1e-4、BF16/math、32×1024、greedy最大32tokenを維持した。64教材は8組の事実設定を記憶/訂正、一項目/二項目、短い/離れた質問に展開したもので、独立した事実設定が64組あるわけではない。

| 評価 | 内容成立 | 補足 |
|---|---:|---|
| 学習前の同じ64問 | 0/64 | 要求値だけなら9件に含まれたが、自然な回答は成立しなかった |
| 学習後の64問 | 64/64 | 全文が教師と一致。自然停止64/64、反復・空・UTF8破損・役割漏れ・履歴切断0 |
| 未学習の値 | 30/32 | 一項目15/16、二項目15/16。残る2件は持ち物を鈴から紐へ訂正する例 |
| 質問表現と配置の変更 | 15/32 | 一項目15/16、二項目0/16。二項目を求めても一つだけ返す傾向 |
| 実生成履歴の16会話の最終回答 | 9/16 | 先行する誤答や断片返答も、そのまま次の履歴に使用 |

学習成立の基準は満たした。次の主SFTを準備する基準は、未知値24/32以上、質問構造24/32以上、実会話12/16以上だった。後二つに届かず、主比較へ進める条件は成立しなかった。損失が下がるだけでなく、短い二情報の出力と一部の値の転用が同じ10Mで可能であることは確認できた。

例えば、同じ事実から「今の名前と好きな花を短く」と問うと二つとも答えられる。しかし、情報順・相づち・質問配置も変えた「好きな花、名前について現在の内容を答えて」では「名前はミナです。」となり、花を落とした。これは複数の変更を組み合わせた評価で、読点や順番のどれが原因かはまだ確定しない。

実会話では、飲み物を煎茶から甘酒へ訂正しても、モデル自身が先に返した煎茶を続ける例が残った。未知値の提供履歴と実会話では質問文なども異なるため、この差を履歴の誤答だけの因果効果とは解釈しない。

## 次に分ける課題

次は学習時間を延ばす前に、**質問から要求項目を二つとも選ぶ処理**を切り分ける。今回の重みを固定し、同じ事実・同じ履歴に対して、質問だけを「AとB」「BとA」「A、B」「両方をそれぞれ」に変える64入力の追加診断を準備する。質問以外を固定すれば、今回まとめて変えた要因の一部を分離できる。CPU生成の計画上限は1200秒、全64応答と実入力を確認し、出力対象の数・値の対応・停止を別に判定する。この追加診断はまだ実行していない。

二項目要求の読み取りが特定表現に偏る根拠が得られた場合、その質問表現の配合だけを変える新しい対照SFTを設計する。一般会話の教材を保ち、同じ教師量・同じ元Baseから比較し、今回の小集合重みを親にしない。実会話の旧値固定は、その後も別の評価で確認する。

今回の固定条件は不採用として閉鎖する。64問の成功を安定したチャットの完成、正式Base認定、独立全pipelineや最終TESTの完了へ読み替えず、未知の全手法や10Mの限界とも結論しない。
