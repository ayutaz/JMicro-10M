# 情報配置を変える教材による新しい対照SFT

2026-10-18。[切り分け159](159_chat_recovery_diagnosis_results.md)を受け、**同じ正答を多様な情報配置から答える学習が、未知の質問と実生成履歴での回答を改善するか**を一つの比較で検証する。ユーザーが指定した4段階のうち新SFTと最終判定を実行するための事前方針で、データ構築前に保存する。

## 変更するものと比較対象

新対照C0は、前回の候補C1が使った固定TRAINをそのまま使う。新候補C1は、そのうち著作2,048対象の入力だけを変える。通常会話、Aya、Dolly、出力の正答文字列、明示alias数、source配合、正答token列と消費順を保持する。過去の候補重みを延長せず、両腕とも元10B Base/fresh Adamから開始する。

著作入力の変更方針は、事実の提示順、質問までの距離、途中の中立な近況、直接質問の言い回しを組み合わせた情報配置の変化とする。全ての入力に正答の根拠を含め、訂正は最後の質問より前に完了させる。過去Assistantは矛盾しない確認・相槌とし、モデルの誤答を教材に混ぜる介入は行わない。字句や距離の各単独効果まで特定する実験ではなく、この一つの入力変更方針全体の比較である。

名前・好み・時刻訂正・数量・所有者・単語転記・加算・不足情報の8群、各256対象を維持する。減算・新英数字・新たな二属性の出力教師をまとめて追加しない。未知の二属性質問や英数字の厳密出力は評価に残し、この比較が全てを解決すると前提にしない。Baseでも弱い能力の別学習は、この比較の結果に応じた別提案とする。

## 教材と教師列の確認

原TRAINは元configのhashを照合して読み、別の外部TRAINディレクトリへ保存する。元データは変更しない。全2,048候補について実際のUser本文だけから答えを独立に抽出・再計算し、元正答と照合する。最終Assistantだけを教師に選び、途中の確認を新たな正解教師へ増やさない。

全変形パターンの対話例を直接確認する。全行の役割順、否定・最新訂正、完全な教師2〜32token、履歴非切断、元正答の全token一致を検証する。候補と対照のtarget message indexは履歴長で変わり得るため、同一の元semantic IDと最終教師token列で対応させる。

両腕の全消費をCPUでreplayし、各更新の教師数・学習率・教師token列のdigest・sourceの実教師数が一致することを確認する。入力token・sampler binding・履歴長・data digestは変更に伴い異なり、その差を保存する。実量や全件QAが成立しなければ、本学習前に失敗と不足を記録する。

今回の100case、履歴診断20family、通常文40件、既存DEVをTRAINへ移さない。TRAIN確定後に新DEVを作る。既存公開診断との完全な意味的非重複を主張せず、近似・同一の教材転用を避けるため照合を行う。新しい封印TESTは使わない。
