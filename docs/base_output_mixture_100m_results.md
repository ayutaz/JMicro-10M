# MoC / MoS 同学習量比較の結果

2026-10-07。両条件の各100,000,000教師tokensの学習、自動評価、全160件の個別内容確認を完了した。MoSは採用条件を満たさず、Baseは未完成・未採用である。Chat・Dialogue・SFT・量子化は開始していない。

元の10Bチェックポイントから、同じ追加行列を持つ二条件を学習した。MoCは文脈を混ぜてから一つのsoftmaxを使い、MoSは各文脈のsoftmax確率を混ぜる。両条件は10,034,434パラメータで、元モデルへの追加は33,282（約0.33%）。同じTRAINデータ列、Web75M・教材20M・物語5M、fresh AdamW、LR1e-5、batch48、seed42、元のEOS監督を保った。今回は学習量を追加しており、新しい教材量を増やした比較ではない。

## 証拠と限界

全160件を個別に読んだ。対照の旧同文73件、候補の同文78件は結果前に固定した参照優先順の採点を保持し、それぞれ新7件・2件も個別の理由を保存した。候補の78件には今回のMoC対照と一致した1件が含まれる。非盲検のCodex評価で、独立人間・独立学習seed・最終TESTの証拠ではない。

両17,698更新・各元gold100Mの終端、optimizer・scheduler・RNG・sampler・全履歴・有限値・metadataを確認し、両条件とcached CEのデータ列に関する全11条件が一致した。科学学習と自動評価はGPU2,950.119308秒、独自の事前検証を含め2,967.255924秒（約49分）で、凍結予算内だった。検証86更新・500,626教師tokensは科学学習量へ足していない。
